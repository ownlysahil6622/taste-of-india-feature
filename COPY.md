## Issues to review

### Spelling mistakes and inconsistent spellings

1. **"Kerela"** (should be "Kerala"):
   - in the React Native map label (`rn/data/tasteOfIndiaMarkers.ts:93`), which users can see;
   - in the eyebrow baked into all six Kerala banner images.
2. **Dish names that don't match the banner title** for the same dish:
   - Gahloti Kebab / **Galouti Kebab**: "Galouti" is the common spelling.
   - Dal Makhni / **Dal Makhani**: "Makhani" is the common spelling.
   - Puran Poli / **Pooran Poli**
   - Chetinad Chicken / **Chettinad chicken**: "Chettinad" is correct, and the web card description already uses it.
   - Mangalorian Buns / **Mangalore Buns**: "Mangalore Buns" is the usual name.
   - Puttu & Kadala Curry / **Puddu kadala curry**: "Puddu" is a typo in the banner.
   - Kappa & Meen Curry / Kappa Meen Curry
   - Lassi / Punjabi Lassi
   - Pongal / Veg Pongal
   - Andhra Meal / Andhra Meals
   - Hyderabadi Biryani / Hyderabadi Dum Biryani
   - Benne Masala Dosa / Masala Dosa: the banner drops "Benne".
   - Pesarattu Dish / Pesarattu: "Dish" in the card name reads oddly.
3. **"Pav Bhaaji"**: the usual spelling is "Pav Bhaji". It's used in both the card and the banner.
4. **Kolhapuri Mutton:** the banner title says **"Kolhapuri Chicken"**, but its description and the card both say mutton, and the photo shows chicken.
5. **Inconsistent capitalisation in banner titles:**
   - Most banner titles use title case, but these use sentence case: "Kosha mangsho", "Gongura mutton", "Guntur chilli chicken", "Ulavacharu chicken biryani", "Natu kodi pulusu", "Chettinad chicken".
   - "Bisi bele Bath" mixes the two.
   - "Mirchi ka Salan", "Double ka Meetha" and "Qubani ka Meetha" use a lowercase "ka" deliberately; that's fine if it's the house style.
6. **US vs UK English:**
   - The code uses UK spelling: "flavours", "yoghurt", "chillies".
   - The banners mix in US spellings: "flavors", "flavorful", "favorite", "specialty", "flavored".
   - The Vada Pav detail sentence uses "favorite" while the template right below it uses "flavours".
7. **Punctuation:**
   - The Vada Pav sentence uses a spaced hyphen ("snack - spiced") where a dash is meant.
   - Two banners use an unspaced em dash ("veggies—Mumbai's", "pickles—an").
8. **"Crisp" vs "Crispy":** card descriptions say "Crisp", while the banners say "Crispy" for the same dishes (Amritsari Kulche, Pesarattu, Masala Dosa).
9. **React Native hint grammar:** "Tap on state to discover regional flavours" is missing an article ("Tap a state…"). The web wording already fixes this.

### Accessibility notes
